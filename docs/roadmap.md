# نقشه‌راه محصول — پیمانه (Peimaneh)

> ایجنت هوشمند اجرای تجارت خارجی — از مکالمه خارجی تا سفارش قطعی

این سند مراحل ساخت محصول را از MVP تا نسخه‌ی بالغ مشخص می‌کند. هر فاز باید یک ارزش قابل‌لمس و قابل‌فروش تحویل بدهد، نه فقط زیرساخت.

---

## اصل راهنما در همه فازها
پیمانه **هرگز** به‌جای انسان تعهد تجاری نمی‌دهد و معامله را نمی‌بندد. هر پیشنهاد قیمت، تخفیف یا شرط پرداختی که از سقف/سیاست شرکت خارج شود، باید قبل از ارسال به تأیید انسان برسد. این قید طراحی، نه یک فیچر جانبی، محور تمام فازهاست.

## وضعیت اجرای فعلی

- **فاز ۱ پایه:** API واقعی contacts، threads، messages، policy و audit؛ dashboard چندصفحه‌ای و Docker Compose آماده است.
- **فاز ۲ پایه:** زمان‌بندی، لغو و تکمیل follow-up، فهرست فرصت‌های موعددار و ثبت رویدادها آماده است؛ worker و اعلان خودکار باقی است.
- **امنیت پایه:** bearer-token، نقش‌های manager/sales، محدودیت policy برای manager و hash امن رمزها آماده است.
- **باقی‌مانده‌های مسدودکننده انتشار:** migration نسخه‌دار، اتصال کانال رسمی، NLU/NLG، worker اعلان، کنترل دسترسی سازمانی و تست deployment production.

هدف: محدود کردن scope به یک use case قابل دمو در کوتاه‌ترین زمان.

- انتخاب **یک** دسته محصول و **یک** بازار هدف مشخص (مثلاً صادرات محصول X به عراق/امارات، یا واردات Y از ترکیه).
- انتخاب **یک** کانال ورودی اولیه — پیشنهاد: **واتساپ + ایمیل** (پرکاربردترین در تجارت خارجی ایرانی).
- انتخاب **یک** جفت زبان اولیه (فارسی ⇄ عربی یا فارسی ⇄ انگلیسی).
- تعریف اولیه‌ی «سیاست شرکت» به‌صورت ساختاریافته: کف قیمت، شرایط پرداخت مجاز، حداقل سفارش، ظرفیت تقریبی.
- خروجی فاز: سند PRD کوتاه + دیتاست نمونه از ۱۰-۲۰ مکالمه واقعی (ناشناس‌شده) برای تست پرامپت‌ها.

## فاز ۱ — دستیار مکالمه (Copilot، بدون خودکارسازی ارسال)
هدف: اثبات ارزش پایه — انسان هنوز روی «ارسال» کلیک می‌کند.

- اتصال read-only به یک کانال (مثلاً forward کردن پیام یا اتصال به ایمیل/واتساپ بیزینس API).
- خلاصه‌سازی مکالمه + تشخیص نیاز طرف مقابل (قیمت؟ نمونه؟ شرایط پرداخت؟ حمل؟).
- تشخیص سطح جدیت خریدار/تأمین‌کننده (سرنخ داغ/سرد).
- پیش‌نویس پاسخ حرفه‌ای به زبان و لحن بازار هدف (Draft، نه Auto-send).
- پیشنهاد سؤالات بعدی که تیم باید بپرسد.
- **معیار موفقیت فاز:** تیم فروش زمان نوشتن پاسخ را حداقل ۵۰٪ کاهش می‌دهد.

## فاز ۲ — پیگیری و حافظه مکالمه (Follow-up Engine)
هدف: جلوگیری از سوختن فرصت‌ها به‌خاطر فراموشی.

- ذخیره‌سازی تاریخچه مکالمه هر مخاطب (thread) با شناسه یکتا.
- تشخیص خودکار «این مکالمه نیاز به پیگیری دارد» + زمان‌بندی یادآوری.
- داشبورد ساده: لیست فرصت‌های باز، مرحله فعلی هرکدام، آخرین پیگیری، پیگیری بعدی.
- اعلان (نوتیفیکیشن داخل پنل یا ایمیل) برای follow-up های فراموش‌شده.

## فاز ۳ — موتور سیاست‌محور مذاکره (Policy-Aware Negotiation)
هدف: اجازه دادن به AI برای پیشنهاد قیمت/شرایط، اما درون چارچوب دقیق شرکت.

- ماژول «سیاست شرکت» به‌صورت config قابل ویرایش توسط مدیر بازرگانی (کف قیمت، پله‌های تخفیف مجاز، شرایط پرداخت پذیرفتنی، ظرفیت واقعی تولید/موجودی، لیست کشورها/مشتریان حساس).
- state machine مذاکره با مراحل مشخص: `inquiry → quote → sample → payment_terms → shipping → proforma → confirmation`.
- Guardrail: هر پیشنهادی که از سیاست خارج شود → به‌جای ارسال خودکار پیش‌نویس، **flag "نیاز به تأیید انسان"** می‌گیرد.
- Escalation rule: کشور/مشتری حساس → همیشه تأیید انسان، حتی اگر داخل سیاست باشد.

## فاز ۴ — مقایسه پیشنهادها (برای واردکننده‌ها)
هدف: باز کردن use case دوم بازار — واردات.

- ورودی چند پیشنهاد از تأمین‌کنندگان مختلف (متن آزاد یا فایل).
- استخراج ساختاریافته: قیمت، حداقل سفارش، زمان تحویل، شرایط پرداخت، Incoterm.
- جدول مقایسه‌ای + پرچم ریسک اولیه (مثلاً شرایط پرداخت غیرمعمول، عدم شفافیت در حمل).
- کمک به تنظیم پیام مذاکره متقابل به تأمین‌کننده.

## فاز ۵ — آماده‌سازی سفارش و اتصال به سیستم‌های داخلی
هدف: رساندن فرصت جدی تا مرحله «قابل تصمیم» برای امضا.

- تولید خودکار پیش‌نویس پیش‌فاکتور (Proforma Invoice) از داده‌های مکالمه.
- اتصال به CRM/ERP موجود شرکت (خواندن کاتالوگ، قیمت پایه، موجودی).
- Export/Sync سفارش تأییدشده به سیستم مالی یا CRM.

## فاز ۶ — گسترش کانال و زبان
هدف: مقیاس‌پذیری افقی بعد از اثبات ارزش در فاز‌های قبل.

- افزودن کانال‌های بیشتر (لینکدین، فرم‌های سایت B2B مثل Alibaba/TradeKey در صورت وجود API).
- افزودن زبان‌های بیشتر (ترکی، روسی، چینی بسته به بازار هدف مشتریان).
- شخصی‌سازی لحن به ازای بازار (مثلاً رسمیت بیشتر برای بازار آلمان، غیررسمی‌تر برای بازار عراق).

## فاز ۷ — تحلیل و بهینه‌سازی
- گزارش نرخ تبدیل فرصت → سفارش، میانگین زمان پاسخ، نرخ follow-up موفق.
- A/B روی لحن/سبک پیام برای بهبود نرخ پاسخ‌دهی طرف خارجی.
- یادگیری از تصمیمات انسانی (چه پیشنهادهایی رد شدند، چه چیزی اصلاح شد) برای بهبود سیاست‌ها.

---

## اولویت‌بندی پیشنهادی برای شروع
اگر منابع محدود است، ترتیب MVP → PMF: **فاز ۰ → ۱ → ۲ → ۳**. فاز ۴ (مقایسه واردات) و فاز ۵ (پیش‌فاکتور) را می‌توان بسته به اینکه مشتری اول صادرکننده است یا واردکننده، جابه‌جا کرد.
